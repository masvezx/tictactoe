# Крестики-нолики · React

Два оформления: обычное (светлое/тёмное) и тетрадь (клетка/линейка).
Поле адаптируется под телефон. Игра с другом, копирование приглашения и три
уровня компьютера работают через существующий FastAPI.

Сложность доступна только в режиме «С компьютером». Кнопка языка рядом с темами
открывает список: русский, сербский (кириллица), немецкий, английский. Весь
интерфейс, ошибки и правила переводятся сразу; язык сохраняется после обновления
страницы. Стрелка справа открывает правила. Закрыть панель можно повторным
нажатием или клавишей Escape. Смена языка не сбрасывает игру.

## Запуск

Требуется Node.js 22.12+ или 24+.
В первом терминале запустите API из соседней папки:

```powershell
Set-Location C:\Users\serge\krestiki\api
uv run fastapi dev src\api\main.py
```

Во втором терминале:

```powershell
Set-Location C:\Users\serge\krestiki\web
npm install
npm run dev
```

Откройте http://localhost:5173. Vite перенаправляет `/api` на порт 8000;
CORS не требуется. Для игры с другого устройства используйте адрес компьютера
в локальной сети, например `http://192.168.1.10:5173`. Разрешите доступ к порту
5173 в брандмауэре только для доверенной сети. Сервер API не нужно открывать наружу.

Создайте игру «С другом», скопируйте ссылку и отправьте другу. Друг открывает
ссылку и нажимает «Присоединиться». Открытие само по себе не занимает место.
Состояние обновляется раз в секунду; повторный вход на том же устройстве
восстанавливает токен из localStorage. Для проверки двух игроков на одном
компьютере используйте разные браузеры или приватное окно.

Токены приватны и не включаются в ссылки. Одна сохранённая партия на браузер;
создание новой заменяет локальный токен. При ошибке копирования ссылка доступна
для ручного выделения. Автокопирование требует HTTPS или localhost.
Игры исчезают при перезапуске API. После сбоя создания/присоединения с потерей
ответа повторное приглашение может потребовать новой игры.

## Сборка

```powershell
npm run build
npm test
```

Результат — `dist`. Для публикации обслуживайте его через HTTPS и перенаправляйте
`/api` на единственный процесс FastAPI на том же домене. Dev proxy работает
только в `npm run dev`; `npm run preview` не заменяет такой reverse proxy.
Ссылки приглашения ведут на `/?invite=...` фронтенда, а не на JSON API.

## Контейнер nginx

Из корня репозитория:

```powershell
docker build --platform linux/amd64 -t tictactoe-web .\web
docker run --rm -p 8080:8080 -e BACKEND_HOST=your-api.example.com tictactoe-web
```

Откройте http://localhost:8080. Обязательная переменная `BACKEND_HOST` задаётся
при запуске контейнера: HTTPS-имя хоста API без `https://`, пути и завершающего
слеша. Например, используйте FQDN backend Container App. Пересборка фронтенда
при смене хоста не нужна. Контейнер не запустится без `BACKEND_HOST`.

nginx обслуживает статические файлы и проксирует `/api/...` по HTTPS, сохраняя
путь и заголовок Authorization. Сертификат API проверяется; самоподписанные
сертификаты не поддерживаются без настройки доверенного центра сертификации.
Браузер обращается только к nginx, поэтому CORS на API не требуется.

В Azure Container Apps задайте frontend ingress target port `8080` и включите
HTTPS для внешнего доступа. Backend ingress target port — `8000`; если оба
приложения находятся в одном Container Apps environment, backend может иметь
internal ingress. Используйте его FQDN в `BACKEND_HOST`, а не `localhost`.
Для backend оставьте одну реплику и не распределяйте трафик между ревизиями:
игры хранятся в памяти одного процесса.
